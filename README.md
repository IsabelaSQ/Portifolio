Bem-vindo(a) ao repositório do meu portfólio pessoal! Desenvolvi este projeto para apresentar meu trabalho, minhas habilidades e os projetos que construí ao longo da minha jornada como Desenvolvedora Front-End.

## 📌 Sobre o Projeto

O portfólio foi projetado com uma interface moderna (Dark Mode nativo com detalhes em neon), com foco em acessibilidade, performance e responsividade. O objetivo principal é proporcionar uma ótima experiência de usuário (UX) enquanto exibe minhas competências técnicas.

## 🚀 Funcionalidades

* **Design Responsivo:** Layout adaptável para qualquer tamanho de tela (Mobile, Tablet e Desktop).
* **Filtro de Projetos:** Galeria interativa que permite filtrar projetos por tecnologia (React, HTML/CSS, JavaScript).
* **Animações Suaves:** Utilização de animações ao rolar a página (AOS) para uma experiência mais dinâmica.
* **Formulário de Contato:** Formulário funcional com validação e feedback visual de envio com sucesso.
* **Download de CV:** Botão de acesso rápido para baixar o currículo atualizado.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **HTML5 & CSS3:** Semântica, Flexbox, Grid, Variáveis CSS e animações.
* **JavaScript (Vanilla):** Lógica para o filtro de projetos, menu mobile e manipulação do DOM.
* **Bibliotecas Extras:** [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) para as animações de entrada.
